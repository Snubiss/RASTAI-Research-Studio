- **PROC-01:** The local verification gate (owner decision of 2026-10-11: the private repository's free GitHub Actions minutes ran out). A git hook, `tools/hooks/pre-push`, runs `just check` before every push and refuses the push if it fails; the new recipe `install-hooks` turns it on with `git config core.hooksPath tools/hooks` (15.9). `ci.yml` and `nightly.yml` keep their jobs but run only on `workflow_dispatch` until the repository is public or a self-hosted runner takes them (15.9). Closing a task now needs `just check` to pass locally and on a fresh clone of the exact PR head, run by the non-author verifier, instead of green CI (12.6; plan 3.3, 3.6, 8.4); macOS and Windows are re-checked when CI returns.
