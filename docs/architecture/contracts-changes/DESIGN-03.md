- **DESIGN-03:** `@rastai/ui` follows the owner-approved design (`docs/design/ui-design.md` §4 and §5). No wire, document, command, event or schema shape changes: the theme file keeps its `rastai.theme/1` shape, and the values in it are data. (1) The built-in `light.theme.json` and `dark.theme.json` take the design's values (roles, `typography.font_sizes_px.xxl` 28, `font_weights.bold` 600, `line_heights.code` 1.45, radius 4/6/10, elevation, the blue/orange `diverging_negative`/`diverging_positive` default, and `colors.confidence_tint` #c75300 light and #f0883e dark), and the font families name Geist and Geist Mono. (2) A third built-in, `packages/ui/src/tokens/high_contrast.theme.json` (`id` `builtin_high_contrast`, `base` `dark`, so it takes the dark locked set), is registered in `built-in-themes.js` under the name `high_contrast`, which `ui.theme` names (5.6, 11.2); `builtInTheme` takes the names `light`, `dark` and `high_contrast` (`BuiltInThemeName`). (3) `applyThemeTokens` emits `--rr-font-size-xxl` (xl's value when a theme leaves `xxl` out, filled in by `resolveTheme`). (4) The Geist and Geist Mono variable woff2 files and `OFL.txt` are bundled under `packages/ui/src/fonts/` (15.8, with a README of the source release and checksums), loaded by `@font-face` in `styles/base.css`; nothing is fetched at runtime. (5) New names in 15.3: `@rastai/ui`'s `StatePill` (with `StateTone`), `SegmentedControl` (with `SegmentOption`) and `StatTile`, and `@rastai/ui/security`'s `TokenConfirm` (the locked "create token" confirmation: what it can and cannot do, a show-once box, Approve disabled until ticked). Their files are `components/StatePill.jsx`, `components/SegmentedControl.jsx`, `components/StatTile.jsx` and `security/TokenConfirm.jsx`, with `security/LockedFocusRing.jsx` (the security UI's focus ring, drawn inside each locked component instead of in `components.css`). (6) `components.css` gains the blocks of the three new components and loses the security focus ring, which the security components now draw. (7) `PanelChrome`'s menu takes focus on open, moves with Up and Down, and returns focus to its button on close (M1-51 sweep follow-up, issue #261). Existing theme files and fixtures keep validating: `fixtures/documents/rastai.theme/valid/every_role.theme.json` now sets all 41 color roles and `xxl`, and its content hash in `content_hashes.json` changes with it; `night.theme.json` and every other stored hash are unchanged. `check-schema-diff` and `check-names` see no change (the new names are JavaScript exports, and the 15.3 package rows are unchanged).
