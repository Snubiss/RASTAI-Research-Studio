**Gaps for M2-03 (Gemma 3 fidelity; optional fields can join `rastai.model/1` later, none is needed for these files):**
- `query_pre_attn_scalar`: Gemma 3 27B scales queries by 168, not by `head_dim` (128). The attention op has no such field yet.
- `gelu_pytorch_tanh`: Gemma's GELU is the tanh approximation. The activation enum's `gelu` is the exact form, so a Gemma 3 design needs a tanh-approximation function added to the enum before it can match the reference.
