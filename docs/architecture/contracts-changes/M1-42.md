- **M1-42 (contract):** Codes for the node's identity and handshake. `rastai-node`'s `identity.rs` loads or creates the Ed25519 keys (`node.key`, and `daemon.key` for the daemon) and `handshake.rs` reads the pinned daemon keys, and no code covered a key file that can't be used: `RRS-S0006` names a failed database or event-log read and `RRS-S3005` a write, and neither tells the user that the fix is the key file's owner and mode, or a fresh pairing. The handshake's freshness checks (the daemon's clock within 5 minutes of the node's, a nonce not seen before; designer flow C3a) had no code either: `RRS-N0002` ("Daemon key not paired with this node") would send a user whose clock is wrong to re-pair, which never helps. Two codes join the handshake range, 0001–0999 (10.3): `RRS-N0006` (an identity key or the pinned-keys file can't be read, created or written, is damaged, or is open to group or others; the node never makes a new key in place of a damaged one, since that would change its id and break every pairing silently) and `RRS-N0007` (a handshake whose challenge is stale or reused). The node layout's code map (11.1) lists them.
