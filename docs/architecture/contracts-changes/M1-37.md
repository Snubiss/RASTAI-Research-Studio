- **M1-37:** `rastai_plugin`'s registry, first base classes, module loader and host client (15.2; plugins layout 11). The package gains `registry.py` (`PluginRegistry`, `REGISTRY_KINDS`), `extension_points.py` (`Recipe` with `restore_state`, `Metric` with `prepare(EvalContext)`), `types.py` (`TrainingContext`, `Batch`, `StepResult`, `EvalContext`, `EvalCase`, `ModelOutput`, `MetricResult`: `StepResult` carries `loss` and `metrics`, `MetricResult` `score`, `threshold` and `details`; the others are empty until the task that first fills them, M1-38 for the trainer's and M5 for the Evaluation plugin's), `job_events.py` (`JobEvents`), `job_control.py` (`JobControl` with all six flags of python layout 1.6: `preempt_requested`, `stop_requested`, `cancel_requested`, `checkpoint_requested`, `paused`, `step_budget`; 15.2 listed only the first three), `errors.py` (`PluginError`), `manifest.py` (`read_manifest`, `manifest_ids`, `ID_FIELD_BY_KIND`), `module_loader.py` (`load_plugin_module`), `host.py` (`PluginHost`, `WorkerHost` with `register`, `connect_worker_host`) and the catalog lookup `find_catalog_entry`. The lookup reads only the generated tables, which hold the first-party plugin catalogs; plugins layout 11.1 used to say the package's lookups included a plugin's own `catalog/errors.json`, and that is dropped: a third-party plugin's `PLG-` codes are handled by `rastai-diag`'s `RuntimeCatalog` (M8), and `find_catalog_entry` returns `None` for them. These names lose their (M1) markers in 15.2, and the names they add are registered there. Choices for the owner's review: `load_plugin_module(manifest)` registers into a new registry of the plugin's own and returns it, so names other code registered can't hide a difference; besides RRS-P0103 (a difference, a missing `register()`, a `register()` that raises, a registry refusal), a module or package that isn't installed is RRS-P3001 (the loader never installs anything; only a `ModuleNotFoundError` counts), a module that raises while it is imported is RRS-P4001, and so is an `ImportError` for a name missing from a package that is installed (the node installs the versions the plugin's lock names, so the missing name is the plugin's own mistake), and a manifest without `python.module`, an entry without its `<kind>_id` or an id two entries share is RRS-P0001. `PluginRegistry.register` refuses an unknown kind or a repeated name with RRS-P0103; `find` and `names` with an unknown kind raise `ValueError`, since engines pass kinds as constants. `WorkerHost` sends the job token in the `rastai-job-token` metadata key (M1-43 (contract)) and opens one channel per call; a refused `Register` raises the node's own code (RRS-J2002), and a node it can't reach, a missing `RASTAI_JOB_TOKEN` or an unusable `job.json` is RRS-J2001. `connect_worker_host` reads only `job_id`, `job_socket_path` and `worker_host_socket_path` from `job.json` (8.4). Markers moved to the milestone that builds each name, following the build order of plugins layout 11.6 (its steps are the milestones): `Sampler` (M3); `Lens`, `SaeLoader`, the reply helpers `reply_ok`, `reply_with_jobs`, `reply_error`, `unknown_command` and the `handle_command` convention (M4, with `HandleCommand` and `command_call.proto`, M4-E01 and M4-E02; `CommandReply` is a protobuf message that doesn't exist yet, so writing the helpers now would mean a hand-written twin of a wire type, and the issue's `commands.py` waits for it); `Converter`, `BenchmarkLoader`, `DataSource` (M5); `NodeType`, `Importer`, `Exporter` (M6); `RewardFunction` (M7); `rastai_plugin.testing.TestHost` and `RecordingEvents` (M8, M8-E04); the `PluginHost` and `WorkerHost` calls other than `register` are named with their milestones in the 15.2 cell. 2.5's grpcio row names the one test that may import grpcio beside `host.py`: `rastai_plugin/tests/test_host.py`, which serves a fake `WorkerHostService` (`check-imports`). `rastai_data` now takes its error codes from `rastai_plugin.catalog` instead of writing them out, and depends on `rastai-plugin`; `rastai-plugin` depends on `rastai-proto`, `rastai-formats` and grpcio (`python/envs/cpu/uv.lock`).
