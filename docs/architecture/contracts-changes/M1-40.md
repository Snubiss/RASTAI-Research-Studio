- **M1-40 (contract):** A code for an unexpected error in a worker. The worker's edge turns every failure of a job into a coded `diagnostic.reported` before it exits 1 (10: a worker never reports a bare traceback), and a package error keeps its own code, but an exception that carries no catalog code (a bug in an engine, a plugin's own exception) had none: python layout 7.5 and 7.9 named it only as "RRS-J1xxx", and the existing crash and exit codes are the node's verdicts on an exit (`RRS-J1001` a signal, `RRS-J1002` the kernel's out-of-memory killer, `RRS-J1003` the node's own kill, `RRS-J1004` an exit with no final record or diagnostic), not a failure the worker saw and reported. `RRS-J1005` joins the crash and exit range, 1000–1999 (10.3): "Worker stopped on an unexpected error", with the job id and the error's type in the message and the traceback in `stderr.log` only. Python layout 7.5 and 7.9 name the code. Catalog entry in `catalog/errors/RRS-J.json`; the generated tables, `docs/reference/errors.md` and `schemas/names.json` are regenerated with `just codegen`.
