# python/rastai_models: the Inspectable runtime

Read the root `CLAUDE.md` and `python/CLAUDE.md` first. The layout is `docs/architecture/layout/python.md` §2.

- **What is here.** The safetensors I/O (M1-34): `io/safetensors_reader.py` (`SafetensorsFile`) and `io/safetensors_writer.py` (`write_safetensors`), and `errors.py` (`ModelError`). The compiler and the TextCNN blocks (M1-35): `compiler/` (`compile_model`, `order_graph`, the op table, `CompiledModel`, `bind_weights` and `init_weights`, `apply_train_modes`) and `blocks/` (`OpModule` and one class per TextCNN op). The rest of layout §2.1 lands in its build-order step (§2.9).
- **Compile only a validated spec.** A ModelSpec reaches `compile_model` through `rastai_formats.load_model_spec`, the one validation; the compiler re-checks nothing that guarantees. An op without an entry in `compiler/op_table.py` is `RRS-M0001`.
- **Parameters are named by graph path**, `<node_id>.<name>` (`CompiledModel.graph_parameters`), and weight files use those names. Op modules hold their parameters directly as `weight` and `bias` and sit in a `ModuleList` in graph order, because a node id may hold a dot.
- **Weights come in two ways only.** `bind_weights` fills from `SafetensorsFile`s, strictly, checking every name and shape before it copies a value (`RRS-M2002`, `RRS-M2003`, `RRS-M2004`); `init_weights` draws from one seeded CPU generator in float32, in graph order, so a seed repeats exactly on any device and dtype. Never pickle, never `torch.load`.
- **Placement is applied, never planned** (contracts 2.4 rule 10): `apply_placement` (M6) will apply the spec's `placement{}` field; the compiler builds every node on the one device it is given.
- **Never parses a safetensors header** (contracts §2.4 rule 10). The reader hands the first 8 bytes to `rastai_formats.read_safetensors_header_length`, then the header bytes to `rastai_formats.check_safetensors_header`, and memory-maps the file only after both accepted it. `check-imports` fails if `io/safetensors_reader.py` imports `struct` or `json`. A new header rule goes into `crates/rastai-formats/src/safetensors/header_check.rs`, never here. `tests/test_safetensors_delegation.py` proves it: with the wheel's checks replaced by ones that refuse everything, every corpus file is refused and no tensor byte is read.
- **One error class.** `ModelError(code, message)` with an `RRS-M` code from contracts §10.3. A file the wheel refused keeps the wheel's own `RRS-E60xx` code (`model_error_from_refusal`), so Rust and Python report a file the same way. A bug in calling code (a dtype safetensors can't hold, metadata that isn't str → str) raises `ValueError`.
- **Writes are atomic.** The writer writes `<name>.partial`, syncs it, renames it over the real name and syncs the folder. A failed write leaves the old file, never a half-written one.
- **Per-op numbers have one source** (layout §2.6): each op module's output shapes, parameter count and FLOPs match `fixtures/ops/<op>.json`, the files Rust live stats match too. `tests/test_op_fixtures.py` walks `op_table.py`, so a new op lands with its golden file; the TextCNN template's counts are in `fixtures/models/textcnn/expected_counts.json` (`tests/test_compile.py`).
- **Observation (M2-02).** Every graph node's output is an observation point named by the node's id, unless the node sets `observe` false. `CompiledModel` calls the `PointHook` in the pass's `ForwardContext` at each point, in graph order, and continues with the tensor the hook returns. `attention_kernel.py` picks the kernel per pass: SDPA by default, math or eager pinned for exact replay, and eager whenever full attention is captured. `model_traits.py` derives `ModelTraits` from the spec's ops; block bodies count for the has_* traits but not for `sliding_node_ids`, which waits for instance paths.
- **Decoder blocks (M2-03).** `blocks/` holds the decoder ops (`attention` in its `mha`, `gqa` and `sliding` variants, `feed_forward`, `rms_norm`, `layer_norm`, `residual_add`, `unembed`), each checked against its golden in `test_op_fixtures.py`. Every op's forward takes `context`; a standalone call (no context) runs eager, which is what the golden FLOPs count. Attention's extra outputs are points `<node path>.<output>` (`head_outputs`, `attention_pattern`, `last_token_attention`), passed to the hook inside the op. The decoder standard points are in `observation.py`, hook-tested in `tests/test_decoder_points.py`. Capture safety (`python/CLAUDE.md` rule 9) applies to the static decode step, which arrives with M3; the parity suite against Hugging Face arrives with the family graphs (M2-05).
- **Corpus.** `fixtures/safetensors/` (33 files and `expected.json`) is shared with Rust (`crates/rastai-formats/tests/safetensors_corpus.rs`). It is written by `tools/fixtures/make_safetensors_corpus.py`; never edit a file by hand.
- Tests are in `tests/test_<module>.py`, CPU only.
