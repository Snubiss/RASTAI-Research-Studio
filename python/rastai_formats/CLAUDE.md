# python/rastai_formats: rastai-formats for Python

Read the root `CLAUDE.md` and `python/CLAUDE.md` first. Every type here is defined once in Rust, in `crates/rastai-formats` (its layout is `docs/architecture/layout/rust-control-plane.md` §4; the generator is §4.9).

- **`rastai_formats/generated/` is generated** by `rastai-formats-codegen` from the type descriptions and never edited by hand: change the Rust struct and its `describe_<type>()`, then run `just codegen`. `just codegen-check` fails when it differs from a fresh run. ruff skips it.
- **One frozen dataclass per type** (keyword-only, fields in the description's order), with `<type>_from_json` and `<type>_to_json`. An optional field is `None` when its key is absent, and `to_json` leaves it out again, so a file read and written back keeps exactly its keys. A JSON key that isn't a Python name is renamed: `$schema` is `schema`, a reserved word gets a trailing underscore (`from_`).
- **No validation and no hashing in Python.** The generated functions only convert. Documents are validated, and content hashes computed, by rastai-formats itself through the PyO3 module `rastai_formats._native` (contracts 2.4 rule 10). `rastai_formats/__init__.py` wraps each of its functions (`read_document`, `load_model_spec`, `write_document`, `content_hash`, `hash_bytes`, `read_safetensors_header_length`, `check_safetensors_header`) in a plain function of the same name that looks the native one up on every call, so a test can stand in for one; a refusal raises `FormatsValidationError` with the diagnostics as JSON. The native functions take and return `bytes`, `str` and plain integers; `check_safetensors_header`'s wrapper parses the accepted header's JSON into a dict, because its caller (`rastai_models/io/safetensors_reader.py`) may not import `json` (`check-imports`).
- **The module is Rust** (`crates/rastai-formats/bindings/python/src/lib.rs`, the only pyo3 user). maturin builds it: `just wheel` makes the wheel in `dist/`, and `just env-cpu` builds it into `rastai_formats/_native.*` for the editable install (git-ignored), rebuilding on every sync so it always matches the Rust sources. Change the Rust, run `just env-cpu`, then the tests.
- **Parity with Rust** is `tests/test_parity.py`: the document corpus (`fixtures/documents/`) gives the codes and paths of each `<name>.expected.json` and the hashes of `content_hashes.json`, and the safetensors corpus (`fixtures/safetensors/`) the verdicts and codes of its `expected.json`, the same files the Rust tests check.
- **Imports nothing internal** (`check-imports`): it is the bottom of the Python stack beside `rastai_proto`.
- Tests are in `tests/test_<module>.py`.
