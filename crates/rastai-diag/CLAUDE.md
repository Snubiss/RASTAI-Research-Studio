# rastai-diag

The bottom crate of the Rust workspace. Its design is `docs/architecture/layout/rust-control-plane.md` section 3; its names are in `docs/architecture/contracts.md` §2.1 and §15.1.

## Local rules

- **No rastai dependencies, ever.** Every other crate depends on this one. It also never depends on tokio.
- **WASM-safe.** It must build for `wasm32-unknown-unknown`, so the browser validator renders the same messages as the CLI. No I/O except `logger.rs`, and only when `init_logger` was given a file.
- **Every user-facing text comes from the catalog.** Messages, titles and fixes live in `catalog/` and reach this crate only through `src/generated/`. A new message is a new catalog entry, not a string literal.
- **`src/lib.rs` is a list of `pub mod` lines** (contracts §12.2). Unit tests sit at the bottom of the file they test.
- **External crates:** serde and serde_json only, in `render_json.rs` and `logger.rs` (layout section 3.3).
- **Generated files** in `src/generated/` start with `// Generated by rastai-codegen. Do not edit.` and are never edited by hand.
- **If the generated tables stop compiling**, `just codegen` can't run either, because rastai-codegen builds on this crate. Set both tables in `catalog_table.rs` and `terms_table.rs` to `&[]`, then run `just codegen`.
